# CADET Lite

This folder contains CADET documentation assets for the Unity project.

## Quick Start

1. Open Unity and go to Tools > Covyne > C.A.D.E.T.
2. Click New to create a build profile.
3. Enter a profile details.
4. Click Save, then select the profile in the main CADET window.
5. Enable Build Steps and click Execute to queue the job.

For the current user documentation, see the published CADET User Manual:

- https://naishtech.github.io/cadet-doc/UserManual/

Use that site as the primary reference for setup, workflows, and feature guidance.
