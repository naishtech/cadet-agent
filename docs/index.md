# Cadet-Agent Documentation

Cross-IDE agent framework for Unity/C# game-development. This site hosts the full rationale, examples, anti-patterns, and decision-making guidance behind the Cadet-Agent framework.

For the condensed agent instruction set, see [cadet-agent.md](https://github.com/naishtech/cadet-agent/blob/main/.cadet/agent/core/cadet-agent.md) in the repository.
