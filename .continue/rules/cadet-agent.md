# Cadet-Agent Continue Rule

- Use `agent/core/README.md` as the framework index.
- Resolve learner tier from `agent/core/LearnerModel.md` and workflow behavior from `agent/core/Workflow.md` before substantial recommendations or code changes.
- Apply the relevant task guidance from `agent/core/Skills`, `agent/core/Guidance`, `agent/core/Standards`, and `agent/core/Templates`.
- Repository-specific policy overlays belong in `agent/policies`.
- Planning artifacts belong in `agent/project-plans` unless an active policy says otherwise.
- Use TDD when testing is valid, reproduce defects before fixing them, and keep regression coverage.
